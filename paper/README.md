# Рукопись

- `manuscript_ru.md` - согласованный русский текст от 04.11.2026.
- `manuscript_ru.pdf` - журнальная версия для «Компьютерных исследований и моделирования», 21 страница.
- `manuscript_crm.tex` - исходник журнальной верстки.
- `fig1_shap_logreg_b.png`, `fig2_shap_catboost.png` - согласованные рисунки статьи.

Это версия для подготовки к подаче, а не опубликованная статья. Поле этического одобрения пока не заполнено, допуск к публикации и благодарности внесены по тексту больницы. До подачи поле должен заполнить автор после получения ответа.

## Сборка

Скачать [официальный шаблон журнала](https://crm.ics.org.ru/uploads/template_2024.zip). Поместить `crm-article.cls`, `rcdthm.sty` и `crm-logo.eps` рядом с `manuscript_crm.tex`. Преобразовать логотип в PDF и выполнить два прохода pdfLaTeX из каталога `paper/`:

```bash
epstopdf --outfile=crm-logo.pdf crm-logo.eps
pdflatex -interaction=nonstopmode -halt-on-error -no-shell-escape manuscript_crm.tex
pdflatex -interaction=nonstopmode -halt-on-error -no-shell-escape manuscript_crm.tex
```

Полученный файл называется `manuscript_crm.pdf`. Контрольные суммы опубликованных файлов обновляются только после проверки верстки. Том, номер и даты принятия оставлены для редакции. Чужие файлы шаблона в публичный комплект не включены.
