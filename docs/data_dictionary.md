# Схема входных данных

Закрытый Excel-файл читается с листа `Sheet1`. Названия ниже должны совпадать буквально с `src/config.py`. Пустые ячейки и строки из пробелов означают пропуск. Код не удаляет пациентов и не исправляет исходные медицинские значения.

Цель: `Рецидив (0 - единичный, 1 - рецидив)`, значения 0/1. Строки с неизвестным исходом не используются для классификации. `N пп` - внутренний уникальный ключ строки, не номер истории болезни. Закрепленный список TEST_IDS совместим только с исходной авторской базой. Нельзя применять его как универсальное разбиение чужого датасета.

## Поля для статистики, исключенные из моделей

Загрузчик `data.clean` также ожидает следующие поля из статистического протокола:
- `Возраст манифестации СД`
- `Количество ДКА в анамнезе`
- `ЛПНП`
- `Тяжелые гипогликемии в анамнезе (0 - нет, 1 - да)`

Количество ДКА в анамнезе исключено из предикторов, поскольку связано с формированием исхода. ЛПНП исключен как расчетный показатель липидограммы. ФИО, даты рождения, номера историй болезни и другие прямые идентификаторы не требуются для обучения моделей и не должны добавляться в публичные примеры.

Возраст взят из поля «на текущий момент», а не пересчитан к дате эпизода. Время определения дозы и лабораторных показателей следует понимать в рамках описания базы и ограничений статьи. Пороговые ассоциации не являются указанием менять лечение.

Клиническую трактовку кодов 0 и категорий осложнений нельзя угадывать по числам. При использовании иной базы нужно согласовать словарь с владельцем данных. Этот документ описывает технический формат текущего исследования.
