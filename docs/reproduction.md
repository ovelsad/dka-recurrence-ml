# Воспроизведение результатов

## Основной расчет

Рабочее окружение исследования: Python 3.11.15. Точные версии основных библиотек указаны в `requirements.txt`. Основной ноутбук включает шаги 0-11 и не запускает TabPFN или SDV. Вспомогательные модули для этих экспериментов сохранены в `src/`, но их зависимости не входят в окружение основного расчета.

Из корня репозитория:

```bash
conda env create -f environment.yml
conda activate dka
python -m ipykernel install --user --name dka --display-name "Python (dka)"
python scripts/run_analysis.py --check-only
python scripts/run_analysis.py
```

До запуска требуется разрешенный доступ к исправленной базе. Путь: `data/raw/новая база на исправления.xlsx`, лист `Sheet1`. Файла в репозитории нет. Формат описан в [словаре](data_dictionary.md). Наличие базы не означает разрешения передавать ее другим лицам.

Выполненный ноутбук записывается в `reports/pipeline_executed.ipynb`, таблицы - в `reports/tables/`, рисунки - в `reports/figures/`. Эти каталоги закрыты для публикации. Команда не обновляет `supplementary/`: новые результаты требуют отдельной проверки.

Полный расчет включает многократный отбор признаков и подбор моделей и может занимать часы. Значение `--timeout` ограничивает длительность одной ячейки. Технические тесты не используют базу и не заменяют полного воспроизведения исследования.

## Кэш и заморозка

В `data/interim/` сохраняется кэш CV. Исправление от 04.11.2026 использует SHA-256 от упорядоченных строк и схемы таблицы, чтобы перестановка пациентов не позволяла взять прогнозы от другого разбиения. Старый формат ключа кэша не используется новым кодом: при полном запуске эти этапы будут пересчитаны.

Исторический отпечаток `fingerprint` остается только для совместимости записи замороженных моделей `final_models.json`. Сам файл закрыт и не включен в публикацию. На чистом запуске запись создается перед финальной оценкой теста, на повторном - сверяется. Отсутствие исходной закрытой записи означает, что читатель создает собственную запись воспроизведения, а не подтверждает дату первоначальной заморозки.

Подготовка репозитория не переобучала модели и не меняла опубликованные численные результаты. Дата расчета исходных сводных таблиц - 27.09.2026. Три сочетания порогов повторно проверены 04.11.2026 на той же базе.

## Метрики и таблицы

Код исторически использует ключ `PR-AUC`, но вычисляет `average_precision_score`. В публичных таблицах этот столбец назван `AP`. Переименование не меняет значения метрики. Пороговый анализ по всей когорте отделен от отбора признаков внутри CV и не используется для конструирования признаков моделей.

Таблицы с округленным `p = 0.000` представлены как `p <0.001`, а не как нулевая вероятность. Столбцы параметров CV описывают модели и фолды, не пациентов. Сводные таблицы не позволяют полностью воспроизвести обучение без исходной базы.

## Рисунки и рукопись

После основного расчета `python paper/make_figures.py` повторно обучает две финальные модели на train по локальной замороженной записи и строит рисунки. В публичный комплект уже включены согласованные рисунки. Генерацию не нужно запускать для чтения статьи.

Сборка PDF описана в [paper/README.md](../paper/README.md).

